# PR #62 补充说明

本说明基于贡献者的关联根认领功能，澄清其边界与验证范围。

- `allowClaimFromLinkedRoots` 是整个看板的设置，默认关闭。开启后，主根为 A、关联根包含 B 的会话可以认领 B 项目任务；任务仍归属 B。
- 需要多根工作区插件提供 `multiRootScope.scopeOf(cwd)`，并且关联目录能够解析为已注册项目。服务缺失或调用抛错时退回主根认领规则。
- 设置只改变认领门禁，不改变创建规则。`taskboard_create` 原本即可通过已注册项目 ID 或可解析的目录路径在其他项目创建任务；`unknown workspaceId` 表示目标项目无法解析，不表示会话主根必须匹配。
- 认领成功不授予额外文件权限。读写、构建、git 操作必须使用任务所属项目目录，并遵守会话已有权限。
- 已认领任务的持有人保护、版本检查、报告及送审纪律保持适用。

新增回归覆盖：协议中的有条件例外、任务目录与权限提示；关联根错误文案随开关变化；无需开启该设置即可通过项目 ID 或目录跨项目创建任务。
